# Sample videos

The repository includes two H.264 clips selected for the RoadLens demo:

| File | Duration | Resolution | Suggested use |
|---|---:|---:|---|
| `13958312-uhd_3840_2160_25fps.mp4` | 11.6 seconds | 3840 x 2160 | Quick processing demonstration |
| `855978-hd_1920_1080_30fps.mp4` | 57.7 seconds | 1920 x 1080 | Full search demonstration |

Upload either file through the application; do not copy it into the application data directory manually. The processor samples and resizes frames before inference, so the original resolution does not determine model input size.

All other video files remain ignored by Git. Only add media that is approved for public redistribution, and keep a local backup clip for presentation day.
